# App para mascotas

Aplicación para registrar mascotas y dar seguimiento a su salud: vacunas, citas veterinarias, peso, registros diarios y ciclo de celo con calendario y notificaciones.

## Stack
- Flutter (Android e iOS)
- Riverpod para estado
- go_router para navegación
- drift (SQLite) para datos locales
- flutter_local_notifications para recordatorios
